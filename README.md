# BIRGE

BIRGE — Telegram-платформа, которая соединяет талантливых выпускников с реальными задачами бизнеса и общественных организаций Казахстана.

## Идея

Бизнес описывает проблему, а AI помогает превратить черновик в понятную карточку задачи: задаёт уточняющие вопросы, оценивает готовность от 0 до 100 и объясняет, что нужно улучшить.

Выпускники создают профиль навыков и интересов, просматривают задачи в формате свайпов и отправляют свои предложения. AI рассчитывает совместимость кандидата с задачей и объясняет результат.

Финальное решение всегда остаётся за человеком: выпускник сам выбирает задачу, а бизнес вручную принимает или отклоняет отклик.

## Технологии

Python, Telegram Bot API, JSON, Explainable AI, Recommendation System.
